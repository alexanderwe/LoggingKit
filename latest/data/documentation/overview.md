# LoggingKit Documentation

## Overview

LoggingKit is a lightweight, extensible logging framework for Apple platforms. It routes log messages through one or more [`LogProvider`](/documentation/LoggingKit/LogProvider) instances and supports categorized logging via [`LogCategories`](/documentation/LoggingKit/LogCategories).
